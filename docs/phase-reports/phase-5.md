# Phase 5 — evaluation and operational preparation

CI is configured for the full backend suite and frontend lint/build on Node 24. The tests use mock HTTP, offline model settings and a Python socket guard. A full-suite attempt in the current runtime was rejected by automatic review for unexpected Microsoft telemetry egress (the native Chroma/ONNX path is suspected, but the source/payload was not independently established); the official telemetry opt-out did not clear that review. The full suite was not retried again. New research/discovery/ingestion tests run independently without initializing that native Chroma path. This is an unresolved full-regression gate, not a successful full-suite result.

The evaluation scorer reports Recall@1/5, MRR/nDCG@5, scope validity, citation target validity and refusal precision/recall. Empty relevance sets do not inflate retrieval scores, and unsampled citation metrics return null. The local evaluation CLI requires a dataset version and environment label, reports slices, and writes metrics without questions or filing text. A real held-out/adjudicated gold corpus remains absent. `local-model-smoke.json` is explicitly synthetic and not a release benchmark.

Query and financial events persist trace, scope/revision, timing, counts, token usage and typed error codes with a seven-day retention rule. An allowlist excludes questions, evidence text, credentials and arbitrary payloads. Call budgets are transactionally persistent. The operator status command flags expired worker leases, failed ingestion, stale queues, citation failures and scope failures. It prints actions but does not configure an external alert service.

Local backup/restore tests use SQLite's consistent backup API and immutable source checksums. A new destination is mandatory; restore refuses corrupt data and rewrites object locations in the restored copy. Tests prove persisted sections, budget reservations, original/amended fact snapshots and source bytes survive this local drill. Container/host replacement, staging rollback, remote retention and a production recovery-time objective are still unverified.

G5 remains **NO-GO**: native full-suite review, staging traces with real Groq usage, actual cost calibration, held-out human evaluation, mobile/accessibility review and production topology remain open. See the operator runbook and release-readiness matrix. No deployment or remote push was performed.
