# Phase 4 — local XBRL snapshots and deterministic preview

The SEC transport now supports an allowlisted companyfacts source-byte fetch through its existing contact, throttle, retry, decoded-byte and TTL policy. Exact response bytes are stored as immutable SHA-256 objects. An append-only fact snapshot pins CIK/accession, filing revision, raw checksum and map version; one transaction changes the active fact-map pointer. Repeated identical source bytes are idempotent. Reads verify the raw checksum and compare normalized facts with persisted records.

Normalization preserves taxonomy/concept, value/unit, instant or duration start/end, form, filed date, fiscal year/period and frame, plus an exact JSON pointer into the raw source. Selection requires the exact filing accession, period, unit and concept. An as-of cutoff is available, conflicting values refuse, and an amendment never automatically replaces an original accession. An explicit new accession/revision is required for restated figures.

The operator-gated `/api/research/financial` route is separately disabled by default. It provides reported values or Decimal YoY, margin, ratio and CAGR using explicit operands. The initial reviewed preview map permits selected US-GAAP concepts in USD, explicit income/revenue margin pairs and two ratio pairs; custom concepts and other units refuse. Unit, taxonomy, instant/duration, period-length and division-by-zero checks apply. Responses contain reported/calculated status, formula, rounding rule, operand values/periods, raw checksum, fact-map version, source pointers and official source links. Groq never selects operands or performs arithmetic in this path.

Synthetic tests cover raw-byte parity, snapshot reopen/idempotency, conflicting facts, changed sources, tampered records, unit/period refusal, original/amendment isolation, financial endpoint flags, and restored fact snapshots. No live SEC companyfacts request was made. [SEC API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) was rechecked on 2026-10-27; its non-custom/entity-wide coverage means missing API facts cannot prove missing disclosure.

G4 remains **NO-GO** for release: held-out real 10-K/10-Q numeric accuracy, human concept/formula review, custom-taxonomy fallback and verified table/footnote cells remain open. A narrative Groq explanation of validated numeric output is also deferred. Rollback: disable `RESEARCH_FACTS_ENABLED` and restore a prior fact-ready pointer; keep every raw source and snapshot.
