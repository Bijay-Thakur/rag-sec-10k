# Phase 3 — local scoped retrieval and research preview

Branch `codex/phases3-5-local`, based on `d71a25d6e52146e598ce8e27df122ecf715540c6`. The dynamic route defaults to disabled, requires a server-only operator token and verified single-instance configuration, and reserves generation calls transactionally in SQLite before contacting Groq. Call reservations survive process restart. The legacy five-filing route remains available.

The pinned local CPU model is `sentence-transformers/all-MiniLM-L6-v2` at revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`, 384 dimensions, normalized. The loader verifies the artifact manifest and uses offline-only loading without remote model code. See ADR 004 and `local-model-smoke.json` for the measured artifact identity and dependency versions. Nine retrieval queries ran across three synthetic filing scopes (10-K, 10-Q, amendment), with real local vectors, persistent publication and a reopened SQLite repository. BM25, dense and RRF ranked the expected Item first on these easy synthetic cases. This is an integration smoke, not evidence of real SEC relevance or production latency.

`research_ready` is a separate atomic revision pointer. Hash diagnostics and table-flattened filings cannot promote. Reads require exact CIK/accession/revision, model identity and vector dimensions; text checksums and vector values are checked again during retrieval. Deterministic intent routing refuses unsupported, numeric and comparison questions in the narrative preview. The separate financial route uses typed operands. Groq receives bounded evidence only; every claim requires a supplied citation ID, generated URLs are rejected, and numeric literals must appear in cited evidence. These checks establish target validity, not semantic faithfulness.

The Explorer has an explicitly local-only question form for research-ready records. Its Next.js server route holds the operator token, refuses Vercel execution and remote backend URLs, and requires local host/origin checks. Readiness state is keyed by CIK plus accession. Answer text renders as plain text and links resolve through server-supplied evidence objects.

G3 remains **NO-GO**: no authentic SEC ingestion samples, container replacement, adjudicated held-out real corpus or Groq human review was performed. Table attribution needs further work before promoting real filings containing flattened tables. Reranking is deferred pending measured gain. Rollback: disable the query flag, retain raw objects and prior revisions, and restore the prior research pointer after review. Nothing was pushed or deployed.
